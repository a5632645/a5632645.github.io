CLC pi 型滤波器

CLC pi 型滤波器由 C1 - L - C2 组成。它的特征频率有两种常用定义：

\[f_{series}=\frac{1}{2\pi\sqrt{L\frac{C_{1}C_{2}}{C_{1}+C_{2}}}}\]

串联等效电容谐振频率（固有频率，无负载时传递函数极点）

\[f_{para}=\frac{1}{2\pi\sqrt{L(C_{1}+C_{2})}}\]

并联近似（EMI/电源滤波手册常用）

Boost 升压电路设计

CCM 模式下按理想变换器（η=100%）设计：

\[D=1-\frac{V_{in}}{V_{out}},\qquad L=\frac{V_{in}D}{\Delta I_{L}f_{sw}},\qquad C_{out}=\frac{I_{out}D}{\Delta V_{out}f_{sw}}\]

电感平均电流 \(I_{L}=\dfrac{I_{out}}{1-D}\)，纹波电流 \(\Delta I_{L}=r\cdot I_{L}\)，峰值 \(I_{pk}=I_{L}+\Delta I_{L}/2\)

SEPIC 电路设计

CCM 模式下按理想变换器（η=100%）设计：

\[D=\frac{V_{out}}{V_{out}+V_{in}},\qquad L_{1}=L_{2}=\frac{V_{in}D}{\Delta I_{L}f_{sw}},\qquad C_{1}=\frac{I_{out}D}{\Delta V_{C1}f_{sw}},\qquad C_{2}=\frac{I_{out}D}{\Delta V_{out}f_{sw}}\]

电感平均电流 \(I_{L1}=I_{out}V_{out}/V_{in}\)、\(I_{L2}=I_{out}\)，纹波电流 \(\Delta I_{L}=r\cdot I_{L}\)，开关管/二极管耐压 \(V_{in}+V_{out}\)
