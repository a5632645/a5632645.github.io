CLC pi 型滤波器

CLC pi 型滤波器由 C1 - L - C2 组成。它的特征频率有两种常用定义：

\[f_{series}=\frac{1}{2\pi\sqrt{L\frac{C_{1}C_{2}}{C_{1}+C_{2}}}}\]

串联等效电容谐振频率（固有频率，无负载时传递函数极点）

\[f_{para}=\frac{1}{2\pi\sqrt{L(C_{1}+C_{2})}}\]

并联近似（EMI/电源滤波手册常用）
