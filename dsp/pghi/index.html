交互式重现

HOP 大小与窗函数类型作为参数提供，窗长按 COLA 条件取 HOP 的 4 / 6 / 8 倍重叠：hann 用 ×4、三项 Blackman-Harris 用 ×6、标准四项 Blackman-Harris 用 ×8 （即窗长 = HOP × 重叠因子），FFT 大小 = 2 × 窗长取最近 2 的幂 （默认 HOP 512 / 三项 Blackman-Harris，即原 playing.cpp 配置）。切换 HOP 或窗函数会重建处理链并清空状态。

使用说明：选择输入源后点击播放/监听即可。拖动音高、切换瞬态模式、HOP 与窗函数均实时生效 （HOP/窗函数切换会清空处理状态，需重新填满窗长采样）。音频文件在本地浏览器中解码，不会上传。 输出为单声道，与 C++ 版一致。
算法：PGHI（Phase Gradient Heap Integration）按幅度从大到小遍历 bin， 先由相位梯度预测相位（分析 hop 的相位增量按拉伸比映射），再把相邻 bin 相位梯度依次外推； 幅度/相位谱由 IFFT 合成为时域后，用预计算的 Blackman 窗 sinc 核插值重采样得到最终输出。 瞬态检测（SuperFlux / DSPark）检测到瞬态时直接重置合成相位，避免相位声码器对打击乐的拖尾模糊。 DSP 核心由 C++ 编译为 WebAssembly（pghi_shifter.wasm），在 AudioWorklet 中运行，主线程仅负责加载与参数传递。

引用项目

  • CristianMoresi/DSPark — header-only C++20 音频 DSP 库；本页 DSPark 瞬态检测即其谱通量（对数滤波器组 + 运行中位数 + 固定增量）的移植。
  • audiojs/stretch — JS 时间拉伸算法库（@audio/stretch），聚合 WSOLA / PSOLA / 多种相位声码器（含 pghi、transient、hybrid 等）。
  • y-fujii/mini_pvdr — 基于 PGHI 的复调音频时间伸缩与变调工具（Python 相位声码器实现）。
  • Hajime-san/phase-gradient-vocoder — “Phase Vocoder Done Right” 的 Rust 实现，支持时间拉伸与变调。

仓库推荐

  • bungee-audio-stretch/bungee — 现代 C++ 相位声码器时间拉伸/变调库，实时或离线；支持变速不变调、变调不变速， 以及连续变化的播放头（含零速/负速），适合 smooth scrub 与慢动作渲染。
