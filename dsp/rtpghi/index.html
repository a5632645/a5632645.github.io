算法流程

记分析 hop \(H_a\)、合成 hop \(H_s\)、拉伸率 \(\alpha=H_s/H_a\)，FFT 长度为 \(M\)。 每一行是一帧，列是 bin。分析帧中心位于 \(rH_a\)，合成帧中心位于 \(rH_s\)。

1 · 分析 STFT

以窗中心为原点，周期 Hann 窗
\(w[n]=0.5-0.5\cos(2\pi n/M_w)\)
帧在 FFT 前循环左移半个窗，使相位以窗中心为参考。这样相位差与 "窗中心频率"的线性项直接对应。输出 \(|X[r,k]|\) 和 \(\varphi[r,k]\)。 WOLA 用同一窗、合成 hop 和窗平方和归一化。

2 · 相位差分 → 边

\(\Delta_t[r,k]=\operatorname{wrap}(\varphi[r+1,k]-\varphi[r,k]-\frac{2\pi H_a k}{M})+\frac{2\pi H_a k}{M}\)
\(\Delta_f[r,k]=\operatorname{wrap}(\varphi[r,k+1]-\varphi[r,k])\)
边 = \(\alpha\Delta_t,\;\alpha\Delta_f\)
中心差分把相邻的两条前向边先平均成节点梯度，再用节点梯度平均成边， 对应论文第 III 节的梯形积分。

3 · 瞬态锚点

用短窗宽带正谱通量检测起音，再在波形上把位置细化到上升沿。对起音帧中 相对起音前明显上升、且能解释长窗幅度的 bin 固定相位：
\(\varphi_{\text{out}}[r,k]=\operatorname{wrap}(\varphi[r,k]-2\pi k\Delta/M)\)
\(\Delta\) 是输出起音位置、分析帧中心与合成帧中心之间的偏移差。

4 · 堆积分

算法 1 逐帧处理：旧帧的 bin 先入堆，按当前帧幅度出堆， 再向左右 bin 扩散；当前帧的锚点也会直接入堆。局部版本从锚点出发， 只在 ±半径帧内积分；双向版本允许沿时间边向过去传播。传播到的格子成为固定相位， 再用逐帧算法补齐其余格子（对应 experiment.py 的 locked 相位）。 全 STFT 堆每次堆空就从剩余最强 bin 重新播种。 路径最弱版本按"沿途最小幅度"排序，相同优先级先走短路径。

5 · 合成与评估

\(y[n]=\frac{\sum_r w[n-rH_s]\,\mathrm{IFFT}\{A[r,k]e^{j\hat\varphi[r,k]}\}[n-rH_s]}{\sum_r w^2[n-rH_s]}\)
幅度沿用输入 STFT。重分析输出并与目标 \(A e^{j\hat\varphi}\) 比较得到 STFT 残差； 闭环残差取每个小格四条边绕一圈的模 \(2\pi\) 余量，并按四角最弱幅度平方加权。

逐帧积分伪代码

for row = 1 .. rows-1:
    pending = { k | |X[row,k]| > tol · max(peak[row-1], peak[row]) } - anchors
    heap    = { (-|X[row-1,k]|, k) | k in pending } ∪ { (-|X[row,k]|, k) | k in anchors[row] }
    while pending is not empty:
        pop the entry with the largest source magnitude (ties: smaller k)
        if source is the previous frame:
            target = (row, k), phase = phase[row-1,k] + timeEdge[row-1,k]
        else:
            target = (row, k±1), phase = phase[row,k] ± freqEdge[row,k]
        if target is pending:
            set phase, push (-|X[target]|, target)

这是“逐帧”基线；页面的锚点重置把锚点作为额外的堆入口，局部前向／双向则改用 全格堆，以当前 bin 幅度或路径最弱幅度为优先级。算法实现见 dsp/rtpghi/rtpghi_core.js，源头是 qwqdsp/labs/rtpghi/rtpghi.py。
