逆向背景

morph.dll 是一个 PE32 VST2 二进制（基址 0x10000000，构建于 2003-10-03）， 唯一导出是 main（位于 0x1000aab0）。其许可证检查（0x1000d230） 会阻止测量宿主获得有效的处理信号，因此该结果仅基于静态分析，未绕过该检查。

处理包装例程 0x1000db40 以 1024 采样为 hop 处理两个独立输入源（输入左/右声道）， 变换路径使用 2048 点复 FFT（0x1000f4b0 / 0x10011350 为正/逆变换）。 逆变换结果是复数时间块，默认模式将其组合为：

\[ L = \text{real} - 0.25 \cdot \text{imag}, \qquad R = \text{imag} - 0.25 \cdot \text{real} \]

中心频谱例程是 0x1000ee20。对每个正频率 bin 计算 A、B 的幅度与 atan2 相位，并生成平滑包络：

  1. 把幅度谱放到 pi 相位斜坡上；
  2. 逆变换并保留实部；
  3. 保留长度 \( \mathrm{clamp}(N \cdot x^3,\, 2,\, N) \) 的中心段；
  4. 施加 \( 0.42 - 0.5\cos + 0.08\cos(2\cdot) \)（Blackman 窗）；
  5. 正变换并取两倍幅度。

x87 指令流中包含十一处对 \(x\) 和 \(1-x\) 的重复乘方。令 \(e_a, e_b\) 为包络， \( r_a = |A|/e_a \)、\( r_b = |B|/e_b \)（各自上限 1000），恢复出的复 bin 公式为：

\[ a_{11} = x^{11}, \qquad b_{11} = (1-x)^{11} \] \[ \text{cross} = (1-y)\, r_a e_b\, e^{i\phi_A} + y\, r_b e_a\, e^{i\phi_B} \] \[ \text{normal} = (1-y)A + yB, \qquad \text{swapped} = (1-y)B + yA \] \[ \text{out} = (1-b_{11})(1-a_{11})\, \text{cross} + b_{11}\, \text{normal} + a_{11}\, \text{swapped} \]

以上由 morph_dsp.py 中的 morph_positive_spectrum 与 render_core 实现，本页为它在浏览器（AudioWorklet）中的实时移植。

接入 WetDry / RoomSize 的大反馈延迟混响网络未能在逆向中验证，属于频谱形态化核心的外围部分。 本页使用 Web Audio 原生卷积混响（ConvolverNode + 指数衰减噪声脉冲响应）提供 Wet/Dry 与 Room 控制：room_size 决定脉冲响应长度与衰减（0.4s~4s 尾音）， wet_dry 在干信号与混响之间交叉淡化。
